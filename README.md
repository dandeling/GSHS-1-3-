# GSHS 1-3 반 커뮤니티 사이트 🏫

경남과학고 1학년 3반 전용 커뮤니티 사이트입니다.
회원 승인제, 과목별 자료 게시판, 실시간 채팅, 캘린더, 벌점제, 흔적 보관 등을 갖춘
완전한 커뮤니티 서비스입니다.

## ✨ 주요 기능

### 1. 회원 / 로그인
- **관리자 승인제**: 가입 신청 → 관리자 승인 후 이용 가능 (승인 전 로그인·글쓰기 불가)
- **학교 이메일 본인인증**: `(기수)gshs-(학번)@g.gne.go.kr` 형식만 가입 (예: `43gshs-1319@g.gne.go.kr`)
- **별명 + 실명 매칭**: 화면엔 별명만, 실명은 관리자만 확인
- **자동 로그인 없음**: 세션 쿠키 → 브라우저 닫으면 로그아웃
- **비밀번호 bcrypt 암호화** 저장
- **계정 상태**: 승인대기 / 활동중 / 정지 / 거절 / 강퇴

### 2. 게시판
- **공지사항** (관리자만 작성)
- **자유게시판**
- **자료공유게시판**: 과목 15개(수학1~3, 물리1·2, 화학1·2, 생명1·2, 통합과학, 정보1·2, 국어, 영어, 기타) × 수행평가/시험 자료 분류
- 글 작성·수정·삭제, 조회수, 페이지 나눔, 댓글

### 3. 반 채팅방
- 실시간 채팅 (3초마다 새 메시지 자동 로드)

### 4. 캘린더
- 일정 보기(모두) / 추가·수정·삭제(관리자만)

### 5. 벌점제 (비속어 필터)
- 비속어 든 댓글·채팅 → 벌점 +1
- **3점 = 하루 정지 · 6점 = 일주일 정지 · 9점 = 강퇴**
- 비속어 목록은 [`src/badwords.js`](src/badwords.js)에서 관리

### 6. 흔적 3개월 보관
- 글·댓글·채팅의 작성/수정/삭제 기록을 3개월간 보관(소프트 삭제)
- 관리자는 글에서 **"흔적 보기"**로 수정·삭제 이력 확인

### 7. 관리자 페이지
- 가입 승인 / 거절 / 정지 / 해제 / 강퇴 / 벌점 초기화
- 회원 실명·학번·이메일·벌점 확인

### 8. 배포 / 자동 업데이트
- `render.yaml`: GitHub에 push하면 사이트 자동 업데이트
- `Dockerfile`: 어디서든 배포 / [`DEPLOY.md`](DEPLOY.md): 배포·도메인(DNS) 안내
- `DATA_DIR`: 배포해도 데이터 유지

## 🛠 기술 스택
- **백엔드**: Node.js + Express + SQLite(better-sqlite3) + bcrypt + JWT
- **프론트엔드**: 순수 HTML · CSS · JavaScript

## 🚀 빠른 시작

```bash
npm install
npm start
# http://localhost:3000
```

기본 관리자 계정: 아이디 `admin`, 비밀번호 `ADMIN_PASSWORD` 환경변수 (미설정 시 `admin1234`)

자세한 배포 방법은 [DEPLOY.md](DEPLOY.md)를 참고하세요.

## 📁 프로젝트 구조

```
├── server.js              # Express 서버 진입점
├── src/
│   ├── db.js              # SQLite 스키마 · 관리자 시딩 · 흔적 정리
│   ├── constants.js       # 과목/분류/이메일 형식
│   ├── badwords.js        # 비속어 목록 (여기서 관리)
│   ├── middleware.js      # 인증·권한·세션·벌점 로직
│   └── routes/            # auth · posts · chat · calendar · admin
├── public/                # 프론트엔드 (HTML/CSS/JS)
├── Dockerfile / render.yaml / DEPLOY.md
```
